# ip-blocklist-checker

A simple Python script that manages a local list of blocked IP addresses. It allows you to view currently blocked IPs, dynamically add a new IP to the blocklist, and check whether a specific IP address is blocked.

## Features
* **Display Current Blocklist:** Loops through and prints all currently blocked IP addresses.
* **Add New IPs:** Prompts the user to input a new IP address and appends it to the list.
* **Instant Verification:** Checks user input against the blocklist and outputs whether the IP is blocked or safe.

## How to Run
1. Make sure you have Python installed on your machine.
2. Open your terminal or command prompt in the project folder.
3. Run the script using the following command:
   ```bash
   python ip-blocklist-checker.py
   ```
